## Veylstrike Arena — Unity Android FPS Source Kit

A developer-oriented Unity/C# source kit for building offline Android arena shooters, now available on Codester.

- **Offline bot matches:** Deathmatch, Team Deathmatch, Capture the Flag, Duel and Last Man Standing.
- **Mobile controls:** touch movement and aiming, primary/secondary fire, zoom and an editable HUD layout.
- **Editable source:** project settings, content/build tools and English buyer documentation.

### Before buying

This is a source project for developers, **not a finished APK or a guaranteed Play Store-ready game**. It requires Unity 2022.3.62f3, content setup, a fresh build and real-device validation. There is no online or LAN multiplayer.
